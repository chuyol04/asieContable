# Reglas de negocio

Estas reglas son contexto para fases posteriores; la Fase 0 no las implementa todavía.

- Una empresa puede tener varias cuentas bancarias.
- OMEGA es un ejemplo de empresa.
- Afirme y BBVA son ejemplos de bancos asociados a OMEGA.
- La información operativa se organiza por empresa y periodo mensual.
- Un depósito podrá cubrir uno o varios montos esperados.
- Un monto esperado podrá cubrirse con varios depósitos.
- Las entregas de efectivo no necesariamente coinciden con los depósitos.
- Los archivos y evidencias se almacenarán posteriormente en Google Drive.
- El sistema guardará referencias y metadatos, no copias permanentes de los PDF.
